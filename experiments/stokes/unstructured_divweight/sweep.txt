# the number we report for "no preconditioner" there is a property of "no preconditioner AND no
# continuity weight", not of the preconditioner alone. The obstacle mesh has never been tested.
#

#   * the scalar also works here  -> the paper's negative control (30.56 % / 11.40 %) is soft,
#     and we need to know that before a reviewer does;
#   * the scalar does NOT work here -> a two-block rescaling suffices on a uniform grid but not
#     on a genuinely unstructured operator, which is the strongest possible form of the claim
#     that the preconditioner is doing the work.
