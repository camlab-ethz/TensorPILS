# The missing control: FEM bare least squares WITH a continuity weight.
#
# The strong-form baseline carries --pi_div_weight and tunes it; the FEM least-squares arm had
# no such knob, so the structured table compared a weighted objective against an unweighted one.
# Measured on the archived sweeps and on gradients:
#
#   PINO w=1    46.05 % / 13.97 %      <- WORSE than the unweighted FEM control
#   FEM  (none) 31.27 % / 10.92 %
#   PINO w=100   1.73 % /  1.37 %      <- 27x, from one scalar
#   PLS  om=256  2.38 % /  1.69 %
#
#   cosine(grad FEM-LS, grad PINO-mse) = 0.993 at w=1, 0.83 at w=300
#   -- i.e. at w=1 the two are nearly the same objective, and the weight is what separates them.
#
# As a norm weight this is diag(I, w^2 I): the pls preconditioner with the velocity block's
# A^-1 replaced by the identity. So this sweep separates what a two-block rescaling buys from
# what the velocity preconditioner adds on top of it -- which is the question the table should
# be answering and currently cannot.
#
# Read with:  python experiments/stokes/galerkin_divweight/compare.py
