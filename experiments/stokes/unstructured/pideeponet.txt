# PI-DeepONet on the obstacle mesh -- the physics-informed baseline that CAN run here.
#
# PINO cannot: its residual is a finite-difference stencil. This one differentiates the
# strong-form Stokes operator by autodiff through a coordinate trunk, so it is defined at any
# point of any mesh. Reporting it is what turns the unstructured table from a walkover into a
# comparison, and it is the honest form of the capability claim.
#
# Settings start from the STRUCTURED study's picks (lr 1e-4, boundary penalty 0.1, continuity
# weight 100, 1024 collocation points). Those were tuned for a Q2/Q1 operator on a uniform grid,
# and the pls arm already showed on this mesh that such a transfer can fail badly (the
# structured Schur weight 256 gave 99.9 % velocity here), so the two decisive knobs are swept
# again before the seeds are spent.
#
# BC is --pideeponet_bc zero: a relative velocity penalty at the mesh's own boundary nodes. An
# autodiff Laplacian at an interior point cannot see a mask, which is why the structured arm
# needs the penalty too. The mollifier is refused -- no closed form vanishes on both boundary
# components of a domain with a hole, and a mollified number is a labelled control here.
