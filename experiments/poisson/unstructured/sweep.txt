# Poisson on the unstructured disc: 3 losses x 3 seeds. See README.md for the question.
#
#     clsubmit experiments/poisson/unstructured/sweep.txt
#     python   experiments/poisson/unstructured/compare.py
#
# Same source distribution (K=4, r=-0.5), same budget and same seeds as
# experiments/poisson/gaot_arch, so the only differences from the structured GAOT runs are the
# DOMAIN (inscribed disc), the MESH (Gmsh triangulation, 4205 nodes vs 64^2 = 4096) and, for the
# pls arm, the PRECONDITIONER (algebraic V-cycle -- the geometric one has no grid here).
#
# lr 1e-3 is not swept again: the structured GAOT sweep found it an interior optimum for all
# three arms at the same architecture and problem size. Sweep before concluding if an arm looks
# anomalous.
#
# The mesh is read from a cache written once, so all nine runs share byte-identical geometry:
#     python -c "from tensorpils.meshing import circle_mesh; circle_mesh(chara_length=0.015, \
#                cache_path='$TENSORPILS_CACHE_PATH/meshes/disc_h0.015.msh')"
#
# SUBMITTING FROM A COMPUTE NODE: `clsubmit` delegates to `clrun`, and `clrun` on a compute node
# RUNS IN PLACE instead of submitting -- it will execute this whole sweep serially on the node
# you are sitting on, and report "OK" with an empty job id. From a compute node use
#     clrun --force-submit -p gpu1 -t 04:00:00 -n <name> -- <the command>
# per line (clsubmit has no --force-submit pass-through), or submit from a login node.
