# Stage 1 -- pick a learning rate per GAOT arm, before spending the 3-seed budget.
#
#     clsubmit experiments/poisson/gaot_arch/lr_sweep.txt
#
# One seed (42), 150 epochs, four rates per loss. Why this exists at all: every FNO arm in
# experiments/baselines/poisson ran at 1e-3, and reusing that rate for a transformer trained
# under plain cosine decay with no warmup would confound "GAOT is worse" with "1e-3 is the wrong
# step size for GAOT". The published GAOT Poisson-Gauss config uses 8e-4 with AdamW, which is
# inside this grid.
#
# Read the pick off the best VALIDATION relative L2 (not the test error -- that is what the
# final runs report, and choosing on it would leak):
#     python experiments/poisson/gaot_arch/compare.py --lr_sweep
#
# Then edit ARM_LR in sweep.txt and submit stage 2. If an arm's optimum sits on an edge of the
# grid, extend the grid rather than accepting the edge -- see the pideeponet note in
# experiments/poisson/poisson_paper/poisson_benchmark/sweep.sbatch for why that matters.
#
# 150 epochs is 30% of the final budget: enough to rank rates, not enough to rank arms.
